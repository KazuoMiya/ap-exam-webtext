| 店舗 | 商品 | 金額 |
|---|---|---|
| A | P1 | 300 |
| A | P2 | 500 |
| B | P1 | 200 |
| B | P3 | 400 |
| B | P2 | 100 |
| C | P1 | 600 |

```sql
SELECT 店舗, SUM(金額) FROM 売上
```

Q: トランザクションの隔離性水準を READ COMMITTED に設定したとき、発生する可能性がある現象の組合せとして、適切なものはどれか。
ア: ダーティリードだけ
イ: ノンリピータブルリードとファントムリード
ウ: ダーティリードとファントムリード
エ: いずれの現象も発生しない
正解: イ
解説: READ COMMITTED はコミット済みのデータだけを読むので、ダーティリードは防げます。しかし読取りのロックをすぐ解放するため、同じ行を読み直したときに値が変わる**ノンリピータブルリード**や、行が増える**ファントムリード**は起こりえます。すべて防ぐには SERIALIZABLE が必要です。
