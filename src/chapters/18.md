## 経営と組織

### 企業の責任と統治

- **CSR**（企業の社会的責任）：利益の追求だけでなく、環境、人権、地域社会など、幅広いステークホルダへの責任を果たす
- **ESG**：環境（Environment）、社会（Social）、企業統治（Governance）。投資家が企業を評価する観点としても使われる
- **SDGs**：国連で採択された、2030年までの持続可能な開発目標
- **コーポレートガバナンス**：経営者を監視・規律し、企業の健全な経営を確保する仕組み
- **コンプライアンス**：法令や社会規範、社内規程を遵守すること

### 組織の形態

| 形態 | 特徴 |
|---|---|
| 職能別組織 | 製造、営業、経理など機能ごとに部門を分ける。専門性を高めやすいが、部門間の調整が難しい |
| 事業部制組織 | 製品や地域ごとに事業部を作り、利益責任を持たせる |
| カンパニー制 | 事業部の独立性をさらに高め、社内の独立した会社のように運営する |
| マトリックス組織 | 職能と事業など2つの軸で組織を作る。1人が2人の上司を持ち、指揮系統が複雑になる |
| プロジェクト組織 | 特定の目的のために各部門から人を集め、目的を達成したら解散する |

### 人材の管理と育成

- **OJT**：職場で実際の仕事を通じて教育する。**Off-JT**：職場を離れた研修で教育する
- **MBO**（目標による管理）：上司と部下が話し合って目標を設定し、その達成度で評価する
- **タレントマネジメント**：従業員の能力や経験を把握し、戦略的に配置・育成する
- **リスキリング**：新しい職務や技術の変化に対応するため、必要なスキルを学び直す
- **ダイバーシティ**：性別、年齢、国籍などの多様な人材を活かす

## 業務分析とデータ利活用

### QC七つ道具

| 道具 | 用途 |
|---|---|
| パレート図 | 項目を件数の多い順に並べた棒グラフと累積比率の折れ線を組み合わせ、**重点的に取り組む項目**を見つける |
| 特性要因図 | 結果（特性）とその原因（要因）の関係を、魚の骨の形で整理する |
| 管理図 | 品質の値を時系列で描き、管理限界線と比べて工程が**安定しているか**を判断する |
| ヒストグラム | データの分布（ばらつきの形）を棒グラフで表す |
| 散布図 | 2つの変数の関係（相関）を点の分布で表す |
| チェックシート | データを漏れなく、簡単に記録・集計する |
| 層別 | データを、機械や作業者などの属性ごとに分けて比べる |

管理図では、管理限界線の外に点が出た場合だけでなく、限界内でも点が中心線の片側に連続して並ぶ、連続して上昇（下降）するなど、**くせ**がある場合も、工程に異常が生じている可能性があると判断します。

### 新QC七つ道具

| 道具 | 用途 |
|---|---|
| 親和図法 | 言語データを、内容の近さでグループにまとめ、問題を明らかにする |
| 連関図法 | 原因と結果が複雑に絡み合った問題を、矢印でつないで関係を明らかにする |
| 系統図法 | 目的を達成するための手段を、階層的に展開する |
| マトリックス図法 | 2つの要素の組合せの関係を、行と列の表で整理する |
| PDPC法 | 予想される事態を想定し、望ましい結果に至るまでの過程を図示する |
| アローダイアグラム法 | 作業の順序と日程を表す |
| マトリックスデータ解析法 | マトリックス図の数値データを解析して、全体を見通しよく整理する |

### OR（オペレーションズリサーチ）

**線形計画法**：製品X（利益3万円）は材料2kgと工数1時間、製品Y（利益2万円）は材料1kgと工数1時間を使う。材料100kg、工数80時間の制約で利益を最大にする。制約の交点 2x ＋ y ＝ 100、x ＋ y ＝ 80 より x ＝ 20、y ＝ 60 で、利益 3 × 20 ＋ 2 × 60 ＝ **180万円**。最適解は制約条件の境界の交点（頂点）のどれかになります。

在庫管理には、在庫が一定量（発注点）を下回ったら決まった量を発注する**定量発注方式**と、決まった周期で必要な量を発注する**定期発注方式**があります。

<div class="box formula" markdown="1">

経済的発注量（EOQ）＝ √（2 × 年間需要量 × 1回当たりの発注費用 ÷ 1個当たりの年間保管費用）

**ABC分析**は、商品などを売上の大きい順に並べて累積比率でA、B、Cにランク分けし、重点的に管理する対象を決める手法です。

### 意思決定の基準

将来の状況が不確実なときの代表的な基準です。

| 基準 | 考え方 |
|---|---|
| 期待値原理 | 各状況の発生確率が分かるとき、期待値が最大の案を選ぶ |
| マクシミン原理 | 各案の**最悪**の結果を比べ、それが最も良い案を選ぶ（悲観的） |
| マクシマックス原理 | 各案の**最良**の結果を比べ、それが最も良い案を選ぶ（楽観的） |
| ミニマックスリグレット原理 | 各状況での最善の結果との差（機会損失）の最大値が最も小さい案を選ぶ |

## 会計と財務

### 財務諸表

| 財務諸表 | 表す内容 |
|---|---|
| 貸借対照表（B/S） | 一定時点の**財政状態**。資産 ＝ 負債 ＋ 純資産 |
| 損益計算書（P/L） | 一定期間の**経営成績**。収益、費用、利益 |
| キャッシュフロー計算書 | 一定期間の現金の流れ。営業活動、投資活動、財務活動に区分する |

### 利益の区分（損益計算書）

| 利益 | 計算 |
|---|---|
| 売上総利益 | 売上高 − 売上原価 |
| 営業利益 | 売上総利益 − 販売費及び一般管理費（本業の利益） |
| 経常利益 | 営業利益 ＋ 営業外収益 − 営業外費用（受取利息や支払利息を含む、通常の活動の利益） |
| 税引前当期純利益 | 経常利益 ＋ 特別利益 − 特別損失 |
| 当期純利益 | 税引前当期純利益 − 法人税等 |

### 損益分岐点

<div class="box formula" markdown="1">

- 変動費率 ＝ 変動費 ÷ 売上高
- **損益分岐点売上高 ＝ 固定費 ÷（1 − 変動費率）**
- 目標利益を達成する売上高 ＝（固定費 ＋ 目標利益）÷（1 − 変動費率）

</div>

<div class="box example" markdown="1">

売上高1,000万円、変動費600万円、固定費300万円。変動費率0.6なので、損益分岐点売上高は 300 ÷ 0.4 ＝ **750万円**。利益100万円を目標にするなら (300 ＋ 100) ÷ 0.4 ＝ 1,000万円。

</div>

### 財務指標

| 指標 | 計算 | 意味 |
|---|---|---|
| ROE（自己資本利益率） | 当期純利益 ÷ 自己資本 × 100 | 株主の資本でどれだけ利益を上げたか |
| ROA（総資産利益率） | 利益 ÷ 総資産 × 100 | 資産全体でどれだけ利益を上げたか |
| 自己資本比率 | 自己資本 ÷ 総資本 × 100 | 高いほど財務が安定している |
| 流動比率 | 流動資産 ÷ 流動負債 × 100 | 短期の支払能力。高いほど安全 |

### 減価償却と棚卸資産

**減価償却**は、建物や機械などの固定資産の取得費用を、使用する期間（耐用年数）にわたって費用として配分する手続です。

- 定額法：毎年同じ額を償却する。（取得価額 − 残存価額）÷ 耐用年数
- 定率法：未償却残高に一定の率を掛けて償却する。初期ほど償却額が大きい

棚卸資産（在庫）の払出単価の決め方には、先に仕入れたものから払い出したとみなす**先入先出法**、仕入のたびに平均単価を計算し直す**移動平均法**、期間全体の平均単価を使う総平均法などがあります。
