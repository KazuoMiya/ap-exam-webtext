## 補講：知的財産と関連法規の詳細

### 著作権の内容

著作権は、**著作者人格権**と**著作権（財産権）**に分かれます。

| 権利 | 内容 | 譲渡 |
|---|---|---|
| 著作者人格権 | 公表権、氏名表示権、同一性保持権（意に反する改変を受けない権利） | できない。著作者だけに属する |
| 著作権（財産権） | 複製権、公衆送信権、翻案権、譲渡権、貸与権など | できる |

開発を委託して著作権の譲渡を受ける契約では、翻案権などを譲渡の対象として明記し、あわせて「著作者人格権を行使しない」という条項を置くのが一般的です。

著作権者の許諾なく利用できる場合（権利の制限）には、次のものがあります。

- **私的使用のための複製**：個人的に、または家庭内などの限られた範囲で使うための複製
- **引用**：公表された著作物を、出所を明示し、自分の文章が主で引用部分が従となる関係で、必要な範囲で利用する
- **プログラムの所有者による複製**：自分が使うために必要な範囲での、バックアップや改変
- **情報解析のための利用**：AIの学習などの情報解析のための複製は、原則として許諾なく行える。ただし、著作権者の利益を不当に害する場合は除かれる

### 特許に関する補足

- 特許を受けるには、産業上の利用可能性、**新規性**、**進歩性**が必要。同じ発明は、先に出願した者に特許が与えられる（**先願主義**）
- **職務発明**：従業者が職務として行った発明。契約や勤務規則であらかじめ定めておけば、特許を受ける権利は発生したときから会社に帰属する。その場合、従業者は相当の利益を受ける権利をもつ
- **専用実施権**は、設定を受けた者だけが実施できる（特許権者自身も実施できなくなる）。**通常実施権**は、複数の者に許諾できる

### 個人情報保護の補足

- **個人関連情報**：Cookieや閲覧履歴など、個人に関する情報のうち、個人情報、仮名加工情報、匿名加工情報のいずれにも当たらないもの。提供先で個人データとして取得されることが想定されるときは、本人の同意が得られていることを確認する必要がある
- **委託**：個人データの取扱いを委託する場合、本人の同意は不要だが、委託元は委託先を監督する義務を負う
- **オプトアウト**による第三者提供：本人の求めがあれば提供を停止することを条件に、あらかじめ通知などをして提供する方法。個人情報保護委員会への届出が必要で、要配慮個人情報には使えない
- **GDPR**（EU一般データ保護規則）：EU域内の個人のデータを保護する。EU域内にいる個人に商品やサービスを提供する域外の事業者にも適用され、違反には高額の制裁金が科される
- **マイナンバー法**：マイナンバーを含む個人情報（特定個人情報）は、法律で定められた目的以外での収集、保管、提供が禁止されている

### 労働に関する補足

- **労働契約法**：有期の労働契約が通算5年を超えて更新された労働者は、申込みによって、期間の定めのない契約に転換できる
- **労働者派遣法**：同じ事業所の同じ組織単位で、同じ派遣労働者を受け入れられる期間は、原則として3年まで。派遣先は、派遣労働者を特定する目的での事前の面接などを行ってはならない
- **裁量労働制**：実際の労働時間ではなく、あらかじめ定めた時間を働いたものとみなす。対象となる業務が定められている
- **労働安全衛生法**：労働者の安全と健康を守る。心理的な負担の程度を把握する検査（ストレスチェック）の制度を定める
- **出向**は、出向元との雇用関係を保ったまま出向先とも雇用関係を結び、出向先の指揮命令を受ける。派遣では、雇用関係は派遣元とだけ結ぶ

### 企業活動と取引に関する法律

| 法律 | 要点 |
|---|---|
| 会社法 | 会社の設立、組織、運営を定める。大会社などには、内部統制の体制の整備の決定を求める |
| 金融商品取引法 | 上場会社に、有価証券報告書と**内部統制報告書**の提出を求める。インサイダー取引を禁止する |
| 独占禁止法 | 私的独占、不当な取引制限（カルテル、入札談合）、不公正な取引方法を禁止する |
| 景品表示法 | 実際より著しく優良、有利と誤認させる表示（優良誤認、有利誤認）を禁止する。広告であることを隠す表示（ステルスマーケティング）も規制する |
| 特定商取引法 | 訪問販売や通信販売などのルールを定める。通信販売では、返品の条件の表示などを義務づける |
| 電子消費者契約法 | 事業者が申込み内容の確認画面を設けていない場合、消費者は操作の誤りによる契約の無効（取消し）を主張できる |
| 資金決済法 | 前払式支払手段（プリペイドカード、電子マネー）、資金移動業、暗号資産交換業などを規制する |

電子商取引では、契約は、承諾の通知が相手に**到達したとき**に成立します。

### 標準化の補足

| 規格、コード | 内容 |
|---|---|
| JANコード | 商品を識別するバーコード。標準は13桁 |
| QRコード | 縦横の2方向に情報をもつ2次元コード。3か所の切出しシンボルで、どの向きからでも読み取れる。誤り訂正の機能をもつ |
| ISBN | 書籍を識別する国際標準の番号 |
| Unicode | 世界の文字を、一つの体系で扱う文字コード。符号化の方式にUTF-8、UTF-16などがある |
| JIS Q 15001 | 個人情報保護マネジメントシステムの要求事項。プライバシーマーク制度の基準 |
| JIS X 8341 | 高齢者や障害者に配慮した、情報通信の機器とサービスの設計指針 |
