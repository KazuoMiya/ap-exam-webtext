## 知的財産権

### 著作権

著作権は、著作物を創作した時点で自動的に発生します（**無方式主義**）。登録や申請は不要です。保護期間は原則として**著作者の死後70年**、法人などの団体名義の著作物は公表後70年です。

<div class="box point" markdown="1">

プログラムは著作物として保護されますが、それを作成するための**プログラム言語**、**規約**（プロトコルなど）、**解法**（アルゴリズム）は保護の対象外です。

</div>

### 著作権の帰属

| 状況 | 著作者（契約などに別段の定めがない場合） |
|---|---|
| 従業員が職務として作成し、法人の名義で公表するもの（**職務著作**） | 法人。プログラムの場合は公表の名義を問わない |
| 外部に**請負契約**で開発を委託した場合 | 実際に作成した**受託者**（ベンダ）。発注者が権利を得るには、契約で譲渡を定める必要がある |
| 派遣労働者が、派遣先の指揮命令のもとで職務として作成した場合 | 派遣先 |

### 産業財産権

| 権利 | 保護の対象 | 存続期間 |
|---|---|---|
| 特許権 | 高度な発明。ビジネスモデル特許も含む | 出願から20年 |
| 実用新案権 | 物品の形状や構造に関する考案 | 出願から10年 |
| 意匠権 | 物品や画像などのデザイン | 出願から25年 |
| 商標権 | 商品やサービスに使うマーク | 登録から10年（更新できる） |

産業財産権は、特許庁に**出願して登録**しなければ権利が発生しません。

### 不正競争防止法

不正な競争を防ぎ、公正な競争を確保する法律です。**営業秘密**として保護されるには、次の3つの要件をすべて満たす必要があります。

1. **秘密管理性**：秘密として管理されている（アクセス制限、「社外秘」の表示など）
2. **有用性**：事業活動に有用な技術上または営業上の情報である
3. **非公知性**：公然と知られていない

そのほか、他人の商品の形態を模倣した商品の販売、不正な利益を得る目的での**ドメイン名の取得**、一定の条件で提供されるデータ（**限定提供データ**）の不正取得なども規制されます。

### ライセンスの形態

| 形態 | 内容 |
|---|---|
| ボリュームライセンス | 多数の利用者分の使用権を一括して契約する |
| サイトライセンス | 特定の場所（事業所など）での使用を一括して許諾する |
| シュリンクラップ契約 | パッケージの包装を破ると、使用許諾契約に同意したとみなす |
| サブスクリプション | 一定期間の利用権に対して料金を支払う |

## セキュリティ関連の法規

| 法律 | 要点 |
|---|---|
| サイバーセキュリティ基本法 | サイバーセキュリティに関する国の基本理念と、国や地方公共団体などの責務を定める |
| 不正アクセス禁止法 | 他人の識別符号（ID、パスワード）の**無断使用**や、脆弱性を突いた侵入などの不正アクセス行為を禁止する。他人の識別符号の不正な取得・保管・**第三者への提供**、識別符号の入力を不正に求める行為（フィッシングサイトの開設など）も処罰の対象 |
| 刑法 | **不正指令電磁的記録に関する罪**（いわゆるウイルス作成罪：正当な理由なくコンピュータウイルスを作成、提供、供用、取得、保管する行為）、電子計算機使用詐欺罪、電子計算機損壊等業務妨害罪など |
| 個人情報保護法 | 個人情報の適正な取扱いについて、事業者の義務を定める |
| 特定電子メール法 | 広告や宣伝のメールの送信は、原則として事前に同意を得た相手にだけ行う（**オプトイン方式**）。送信者の表示や、受信拒否の方法の表示も義務づける |
| 電子署名法 | 本人による一定の要件を満たす電子署名が行われた電磁的記録は、真正に成立したものと推定する |
| 情報流通プラットフォーム対処法 | 旧プロバイダ責任制限法を改正し、2025年4月に施行。権利侵害情報についてのプロバイダの責任の範囲、発信者情報の開示請求、大規模なプラットフォーム事業者の削除対応の迅速化・透明化を定める |

### 個人情報保護法の要点

| 用語 | 内容 |
|---|---|
| 個人情報 | 生存する個人に関する情報で、氏名などで特定の個人を識別できるもの。マイナンバーや指紋データなどの**個人識別符号**を含むものも該当する |
| 要配慮個人情報 | 人種、信条、病歴、犯罪の経歴など、不当な差別や偏見が生じないよう特に配慮を要する情報。取得には原則として本人の同意が必要で、オプトアウトによる第三者提供はできない |
| 仮名加工情報 | 他の情報と照合しない限り特定の個人を識別できないように加工した情報。社内での分析などに使う |
| 匿名加工情報 | 特定の個人を識別できず、元の個人情報に復元できないように加工した情報。一定のルールのもとで本人の同意なく第三者に提供できる |

個人データを第三者に提供するときは、原則として**本人の同意**が必要です。また、漏えいなどが発生し、個人の権利利益を害するおそれが大きい場合は、個人情報保護委員会への報告と本人への通知が義務づけられています。

## 労働関連・取引関連の法規

### 労働関連

- **労働基準法**：労働条件の最低基準を定める。法定労働時間を超えて働かせるには、労使で**36協定**を結んで届け出る必要がある。フレックスタイム制、裁量労働制などの柔軟な働き方の制度も定める
- **労働者派遣法**：派遣労働者の保護のためのルール。派遣先が指揮命令を行う。派遣先が受け入れた派遣労働者をさらに他社へ派遣する**二重派遣**は禁止
- **公益通報者保護法**：組織の法令違反を通報した労働者を、解雇などの不利益な取扱いから保護する

### 契約形態と偽装請負

| 契約 | 完成の責任 | 作業者への指揮命令 |
|---|---|---|
| 請負 | あり | 受注者（請負事業者） |
| 準委任 | なし（善管注意義務を負う） | 受注者 |
| 労働者派遣 | なし | **派遣先** |

請負契約や準委任契約でありながら、発注者が受注者の作業者に直接指揮命令する状態は**偽装請負**で、違法です。

### 取引関連

<div class="box trend" markdown="1">

**中小受託取引適正化法（取適法）**：2026年1月1日、下請代金支払遅延等防止法（下請法）が改正され、名称と内容が変わりました。主な変更点は次のとおりです。

- 用語の変更：「親事業者」→「委託事業者」、「下請事業者」→「中小受託事業者」など
- 適用基準に、資本金の基準に加えて**従業員数の基準**を追加
- 対象取引に**特定運送委託**を追加
- 中小受託事業者からの価格協議の求めに応じず、**一方的に代金を決定すること**を禁止
- **手形払い**などを禁止
- 発注内容の明示を、相手方の承諾がなくても電子メールなどの電磁的方法で行えるようになった

委託事業者には、発注内容の明示、支払期日（受領から60日以内）の設定、取引記録の作成・保存、遅延利息の支払いなどの義務があります。

</div>

- **フリーランス法**（特定受託事業者に係る取引の適正化等に関する法律、2024年11月施行）：従業員を使用しない個人の事業者（フリーランス）に業務を委託する事業者に、取引条件の明示、報酬の支払期日の設定、ハラスメント対策などを義務づける
- **製造物責任法（PL法）**：製造物の欠陥によって生命、身体、財産に損害が生じた場合、製造業者は過失がなくても賠償責任を負う。ソフトウェア単体は「製造物」（製造または加工された動産）に当たらないが、ソフトウェアを組み込んだ機器は対象になる

## その他の法律・ガイドラインと技術者倫理

- **電子帳簿保存法**：帳簿や書類の電子保存の要件を定める。電子取引で受け取ったデータは、電子データのまま保存する
- **e-文書法**：法令で保存が義務づけられた書類を、電磁的記録で保存することを認める
- **技術者倫理**：公衆の安全や健康を最優先し、専門家として誠実に行動する。**コンプライアンス**や、**情報倫理**（ネチケット、個人情報への配慮）も含む

## 標準化

### 標準の種類

| 種類 | 内容 | 例 |
|---|---|---|
| デジュレスタンダード | 公的な標準化機関が定めた標準 | ISO、IEC、JIS |
| デファクトスタンダード | 市場での競争の結果、事実上の標準になったもの | 広く普及した製品の形式 |
| フォーラム標準 | 関心のある企業などが集まって作った標準 | W3C のWeb標準 |

### 主な標準化団体

| 団体 | 内容 |
|---|---|
| ISO | 国際標準化機構。工業製品や管理の仕組みの国際規格 |
| IEC | 国際電気標準会議。電気・電子技術の国際規格 |
| ITU | 国際電気通信連合。通信の国際規格 |
| IEEE | 米国電気電子学会。LANの規格（IEEE 802 シリーズ）など |
| IETF | インターネットの技術を標準化し、RFCとして公開する |
| W3C | HTML、CSSなどのWeb技術を標準化する |
| JISC | 日本産業標準調査会。JISを審議する |

### 主なマネジメントシステム規格

| 規格 | 対象 |
|---|---|
| ISO 9001 | 品質マネジメントシステム |
| ISO 14001 | 環境マネジメントシステム |
| ISO/IEC 27001 | 情報セキュリティマネジメントシステム |
| ISO/IEC 20000-1 | サービスマネジメントシステム |
| ISO 22301 | 事業継続マネジメントシステム |
| ISO 31000 | リスクマネジメント（指針） |
| ISO 26000 | 組織の社会的責任（手引。認証用の規格ではない） |
