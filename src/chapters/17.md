## ビジネスシステム

| システム | 内容 |
|---|---|
| POSシステム | 販売時点で商品の情報を収集し、売上や在庫の管理、売れ筋の分析に使う |
| EDI | 企業間で、受発注などの取引データを標準化された形式で電子的に交換する |
| RFID | 電波を使って、ICタグの情報を非接触で読み書きする。複数のタグを一度に読み取れる |
| トレーサビリティ | 製品の生産から流通、消費までの履歴を追跡できるようにする |
| GIS | 地図と位置に関連付けた情報を、重ねて表示・分析する |
| ICカード、電子マネー | ICチップに情報を記録し、決済や認証に使う |

## エンジニアリングシステム

### 設計と生産の支援

| 用語 | 内容 |
|---|---|
| CAD | コンピュータを使って設計や製図を行う |
| CAM | CADの設計データを使って、工作機械の加工を制御する |
| CAE | コンピュータ上で強度や熱などを解析し、設計を検証する |
| FMS | 多品種少量生産に柔軟に対応できる、自動化された生産システム |
| PLM | 製品の企画から設計、生産、保守、廃棄までの情報を一元管理する |
| コンカレントエンジニアリング | 設計と生産準備など、本来は順番に行う工程を並行して進め、開発期間を短縮する |
| デジタルツイン | 現実の設備や製品の状態をセンサで集め、仮想空間に再現してシミュレーションや予測に使う |

### 生産方式

- **ジャストインタイム（JIT）**：必要なものを、必要なときに、必要な量だけ生産する。後工程が前工程に部品を引き取りに行き、その指示に**かんばん**を使う
- **セル生産方式**：1人または少人数のチームが、製品の組立てを最初から最後まで担当する。多品種少量生産に向く
- **ライン生産方式**：工程ごとに作業者を配置し、流れ作業で生産する。少品種大量生産に向く
- **BTO**：注文を受けてから、顧客の仕様に合わせて組み立てる

### MRP（資材所要量計画）

生産計画から、必要な部品の量と発注時期を計算する手法です。部品表（BOM）を使って、製品1個当たりに必要な部品の数を展開します。

<div class="box formula" markdown="1">

- 総所要量 ＝ 製品の生産量 × 製品1個当たりの部品の使用数
- **正味所要量** ＝ 総所要量 − 引当可能な在庫量 − 入荷予定量（発注残）（＋ 安全在庫）

</div>

<div class="box example" markdown="1">

製品Xを50個作る。Xには部品Yが2個必要。Yの在庫は30個、入荷予定が20個ある。総所要量 ＝ 50 × 2 ＝ 100個、正味所要量 ＝ 100 − 30 − 20 ＝ **50個**。

</div>

## e-ビジネス

### 電子商取引の形態

| 形態 | 例 |
|---|---|
| BtoB | 企業間の取引（電子調達、EDI） |
| BtoC | 企業と消費者の取引（オンラインショップ） |
| CtoC | 消費者間の取引（ネットオークション、フリマアプリ） |
| GtoC | 行政と市民の取引（電子申請） |

### ビジネスモデルと用語

| 用語 | 内容 |
|---|---|
| ロングテール | 個々の売上は少ないニッチな商品でも、品ぞろえを増やすことで全体として大きな売上になる。在庫と陳列の制約が小さいネット販売で成り立つ |
| O2O | オンライン（Web、アプリ）での情報提供で、実店舗（オフライン）への来店を促す |
| アフィリエイト | Webサイトに広告を掲載し、閲覧者が広告経由で商品を購入すると、サイトの運営者に報酬が支払われる |
| リスティング広告 | 検索エンジンの検索語に連動して表示される広告 |
| SEO | 検索エンジンの検索結果で上位に表示されるよう、Webサイトを最適化する |
| エスクローサービス | 売り手と買い手の間に第三者が入り、代金の受渡しを仲介して取引の安全を保証する |
| クラウドファンディング | インターネットを通じて、不特定多数の人から資金を集める |
| サブスクリプション | 一定期間の利用権に対して、定額の料金を支払う |
| シェアリングエコノミー | 個人が保有する遊休資産（部屋、車、スキル）を、他の人と共有・貸し借りする |

### フィンテックとブロックチェーン

**フィンテック**は、金融と情報技術を組み合わせた革新的なサービスです。スマートフォン決済、個人の資産運用の自動化、オンラインの融資などがあります。

**ブロックチェーン**は、取引の記録（ブロック）を、前のブロックのハッシュ値を含めて鎖のようにつなぎ、多数の参加者で分散して管理する技術です。記録の改ざんが極めて困難で、暗号資産のほか、契約を自動で実行するスマートコントラクトやトレーサビリティにも使われます。

## 民生機器と産業機器

- **IoT家電**：ネットワークに接続し、スマートフォンから操作したり、使用状況を送信したりする
- **スマートメーター**：電力などの使用量を計測し、通信機能で事業者に自動で送る
- **産業用ロボット**、**協働ロボット**（人と同じ空間で安全柵なしに作業できる）
- **ドローン**：遠隔操作や自動操縦で飛行する無人航空機。点検、測量、物流に使われる
- **スマート農業**：センサやロボットで農作業を省力化・高度化する
- **MaaS**：複数の交通手段を、検索・予約・決済まで一つのサービスとして統合する

### 自動運転のレベル

| レベル | 内容 |
|---|---|
| レベル0 | 運転自動化なし |
| レベル1 | 運転支援。アクセル・ブレーキ操作か、ハンドル操作のどちらかを支援する |
| レベル2 | 部分運転自動化。アクセル・ブレーキ操作とハンドル操作の両方を支援する。運転の主体はドライバ |
| レベル3 | 条件付運転自動化。特定の条件下でシステムがすべての運転を行い、作動の継続が難しい場合はドライバが対応する |
| レベル4 | 高度運転自動化。特定の条件下で、システムがすべての運転を行い、ドライバの対応を必要としない |
| レベル5 | 完全運転自動化。条件の限定なく、システムがすべての運転を行う |
