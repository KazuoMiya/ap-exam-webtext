## UIとUXの基本

### ユーザビリティとアクセシビリティ

**ユーザビリティ**（使いやすさ）は、ISO 9241-11 で「特定の利用者が、特定の利用状況で、指定された目標を達成するために用いられる際の、**有効さ**、**効率**及び**利用者の満足度**の度合い」と定義されています。

**アクセシビリティ**は、高齢者や障害のある人を含む誰もが情報やサービスを利用できることです。Webでは国際的なガイドライン WCAG や、日本の JIS X 8341 シリーズが基準になります。画像に代替テキストを付ける、色だけで情報を伝えない、キーボードだけで操作できるようにするといった配慮が基本です。

**ユニバーサルデザイン**は、年齢や能力にかかわらず、最初からできるだけ多くの人が使えるように設計する考え方です。

### 人間中心設計（HCD）

利用者のニーズを中心に置き、評価と改善を繰り返す設計プロセスです（JIS Z 8530 ／ ISO 9241-210）。利用状況の理解 → 要求事項の明示 → 設計による解決策の作成 → 評価 を反復します。

### UXデザインの手法

| 手法 | 内容 |
|---|---|
| ペルソナ | 典型的な利用者像を、名前や年齢、行動、目標まで具体的に設定した架空の人物 |
| カスタマージャーニーマップ | 利用者がサービスを知ってから利用し終えるまでの行動・思考・感情を時系列で可視化する |
| プロトタイピング | 試作品を早期に作り、利用者の反応を見て改善する |
| A/Bテスト | 2つの案を利用者に無作為に提示し、成果を比較して優れた方を採用する |

## ユーザビリティの評価手法

| 手法 | 実施者 | 内容 |
|---|---|---|
| ヒューリスティック評価 | 専門家 | 経験則（ガイドライン）に照らして問題点を洗い出す |
| 認知的ウォークスルー | 専門家 | 利用者になりきって操作手順を一つずつたどり、迷う箇所を探す |
| 思考発話法 | 利用者 | 考えていることを声に出しながら操作してもらい、観察する |
| ユーザテスト | 利用者 | 実際の利用者に課題を与えて操作してもらい、成功率や所要時間を測る |
| アンケート | 利用者 | 満足度などを質問紙で集める |

## GUIの部品

| 部品 | 使いどころ |
|---|---|
| ラジオボタン | 複数の選択肢から**1つだけ**を選ぶ |
| チェックボックス | 複数の選択肢から**いくつでも**選べる。オンとオフの切替え |
| プルダウンメニュー（リストボックス） | 選択肢が多く、画面の領域を節約したいとき |
| テキストボックス | 自由な文字を入力する |
| スピンボタン | 数値を少しずつ増減させる |

入力画面では、入力項目の順序を業務の流れに合わせる、必須項目を明示する、入力エラーの理由と直し方を具体的に示す、既定値を設定して入力の手間を減らすといった工夫が求められます。

## 画像・音声・動画

### データ量の計算

<div class="box formula" markdown="1">

- 画像のデータ量 ＝ 横の画素数 × 縦の画素数 × 1画素のビット数 ÷ 8（バイト）
- 動画のデータ量（非圧縮） ＝ 1フレームのデータ量 × フレームレート × 秒数

</div>

<div class="box example" markdown="1">

1,920 × 1,080 画素、24ビットフルカラーの画像は 1,920 × 1,080 × 3 ＝ 6,220,800バイト（約6.2Mバイト）。この画像を毎秒30フレームで再生すると、1秒で約 **187Mバイト** になります。動画に圧縮が欠かせない理由です。

</div>

### 圧縮方式

| 種類 | 内容 | 例 |
|---|---|---|
| 可逆圧縮 | 圧縮前のデータを完全に復元できる | ZIP、PNG、GIF、FLAC |
| 非可逆圧縮 | 人が気づきにくい情報を捨てて、高い圧縮率を得る | JPEG、MP3、AAC、MPEG、H.264、H.265 |

動画の圧縮では、1枚ごとの圧縮（フレーム内圧縮）に加えて、前後のフレームとの差分だけを記録する**フレーム間予測**で大幅にデータを減らします。

### 色の表現

ディスプレイは光の三原色 **RGB**（加法混色）、印刷はインクの **CMY**（減法混色）に黒（K）を加えた CMYK で色を表します。

## マルチメディアの応用

### コンピュータグラフィックス（CG）

- **レンダリング**：3次元のデータから画像を生成する処理
- **レイトレーシング**：視点から光線を逆にたどり、反射や屈折を計算して写実的な画像を作る
- **テクスチャマッピング**：物体の表面に模様の画像を貼り付ける
- **アンチエイリアシング**：斜めの線などに生じるギザギザ（ジャギー）を目立たなくする
- **ポリゴン**：立体の表面を多角形の集まりで表す

### 仮想現実と拡張現実

| 用語 | 内容 |
|---|---|
| VR（仮想現実） | コンピュータが作った仮想空間に、利用者が入り込んだような体験をさせる |
| AR（拡張現実） | 現実の映像に、コンピュータが作った情報を重ねて表示する |
| MR（複合現実） | 現実空間と仮想空間を融合させ、仮想の物体を現実の物のように操作できる |
| メタバース | 多数の利用者がアバターで交流できる、インターネット上の3次元仮想空間 |
