## 補講：アルゴリズムの設計技法とプログラムの基礎知識

### リストの挿入と削除

単方向リストは、各要素が「データ」と「次の要素へのポインタ」をもちます。

- **挿入**（要素 P の直後に新しい要素 N を入れる）：N の次ポインタに P の次ポインタの値を入れ、その後で P の次ポインタを N に向ける。順番を逆にすると、元の後続の要素をたどれなくなる
- **削除**（要素 P の直後の要素 D を削除する）：P の次ポインタに D の次ポインタの値を入れる

先頭への挿入と削除は O(1) ですが、末尾への追加は、末尾を指すポインタを別に持たなければ先頭からたどる必要があり O(n) です。

### グラフの探索

- **深さ優先探索**（DFS）：進めるところまで進み、行き止まりになったら戻る。**スタック**（または再帰）で実現する
- **幅優先探索**（BFS）：出発点に近い節点から順に調べる。**キュー**で実現する。辺の重みがすべて同じなら、最短経路が求まる

### アルゴリズムの設計技法

| 技法 | 考え方 | 例 |
|---|---|---|
| 分割統治法 | 問題を小さな部分問題に分けて解き、結果をまとめる | クイックソート、マージソート、2分探索 |
| 動的計画法 | 部分問題の解を表に記録して再利用する | 最長共通部分列、ナップサック問題、最短経路 |
| 貪欲法 | その時点で最も良く見える選択を繰り返す。常に最適とは限らない | ダイクストラ法、ハフマン符号 |
| バックトラック法 | 解の候補を順に試し、行き詰まったら一つ前に戻って別の候補を試す | 8クイーン問題、数独 |

### 手続の呼出しと変数

- **値渡し**：引数の値の複写を渡す。呼び出された側で変更しても、呼出し元の変数は変わらない
- **参照渡し**：変数の場所（参照）を渡す。呼び出された側での変更が、呼出し元の変数に反映される
- **局所変数**は手続の中だけで有効で、**大域変数**はプログラム全体から参照できる
- **再入可能**（リエントラント）：複数のタスクから同時に呼び出されても、正しく動作する性質。大域変数を書き換えず、局所変数だけを使う

### 文字列の探索

文字列の中から特定のパターンを探す処理では、先頭から1文字ずつずらして照合する方法のほか、パターンの末尾から照合し、不一致のときに一度に大きくずらす**BM法**（ボイヤー・ムーア法）があります。

### プログラム言語の分類

| 分類 | 特徴 | 例 |
|---|---|---|
| 手続型 | 処理の手順を順に記述する | C |
| オブジェクト指向 | データと操作をまとめたオブジェクトの相互作用で記述する | Java、C++、Python |
| 関数型 | 関数の適用と組合せで記述する。副作用を避ける | Haskell |
| 論理型 | 事実と規則を記述し、推論で答えを導く | Prolog |
| スクリプト言語 | 簡易な記述ですぐ実行できる | Python、JavaScript、Ruby |

変数の型を実行前に決める方式を静的型付け、実行時に決める方式を動的型付けといいます。
