## 経営戦略の手法

### 環境分析

| 手法 | 内容 |
|---|---|
| SWOT分析 | 内部環境の**強み**（S）と**弱み**（W）、外部環境の**機会**（O）と**脅威**（T）を整理する |
| 3C分析 | 顧客（市場）、競合、自社の3つの観点で分析する |
| PEST分析 | 政治、経済、社会、技術のマクロ環境を分析する |
| ファイブフォース分析 | 業界の競争要因を、既存企業間の競争、新規参入の脅威、代替品の脅威、買い手の交渉力、売り手の交渉力の5つで分析する |
| バリューチェーン分析 | 企業の活動を主活動（購買物流、製造、出荷物流、販売・マーケティング、サービス）と支援活動に分け、どこで価値が生まれているかを分析する |

<div class="box caution" markdown="1">

SWOTの強み・弱みは**自社の内部**、機会・脅威は**外部の環境**です。「競合他社の撤退」は自社の強みではなく、外部の機会です。

</div>

### PPM（プロダクトポートフォリオマネジメント）

市場成長率と相対的市場占有率の2軸で事業を4つに分類し、経営資源の配分を考えます。

| 分類 | 市場成長率 | 市場占有率 | 方針 |
|---|---|---|---|
| 花形 | 高 | 高 | 成長を維持するための投資が必要。資金の出入りがともに大きい |
| 金のなる木 | 低 | 高 | 少ない投資で大きな資金を生む。他の事業の資金源 |
| 問題児 | 高 | 低 | 投資して花形に育てるか、撤退するかを判断する |
| 負け犬 | 低 | 低 | 撤退や縮小を検討する |

### 成長と競争の戦略

**アンゾフの成長マトリクス**は、製品と市場をそれぞれ既存と新規に分けて、成長の方向を4つに整理します。

| | 既存製品 | 新製品 |
|---|---|---|
| 既存市場 | 市場浸透 | 製品開発 |
| 新市場 | 市場開拓 | 多角化 |

ポーターの**競争戦略**には、コストで優位に立つ**コストリーダーシップ戦略**、製品やサービスの独自性で優位に立つ**差別化戦略**、特定の市場に絞る**集中戦略**があります。

コトラーの**競争地位別の戦略**は、市場での地位に応じた基本方針を示します。

| 地位 | 戦略の方針 |
|---|---|
| リーダ | 市場全体の拡大と、シェアの維持。全方位の戦略 |
| チャレンジャ | リーダとの差別化で、シェアの拡大を狙う |
| フォロワ | リーダの戦略を模倣し、効率化で利益を確保する |
| ニッチャ | 大手が狙わない特定の市場（すき間）に特化し、独自の地位を築く |

そのほか、自社の中核となる強みである**コアコンピタンス**、優良企業の方法を比較して取り入れる**ベンチマーキング**、競争のない新しい市場を作る**ブルーオーシャン戦略**、他社との提携である**アライアンス**、企業の合併・買収である**M&A**などが頻出です。

## マーケティング

### マーケティングの枠組み

- **STP**：市場を細分化し（セグメンテーション）、狙う市場を決め（ターゲティング）、自社の立ち位置を明確にする（ポジショニング）
- **4P**（売り手の視点）：製品（Product）、価格（Price）、流通（Place）、販売促進（Promotion）
- **4C**（買い手の視点）：顧客価値、顧客コスト、利便性、コミュニケーション

### 製品ライフサイクル

| 段階 | 特徴と戦略 |
|---|---|
| 導入期 | 認知度が低い。製品の認知を高める広告に投資する |
| 成長期 | 売上が急増し、競合が参入する。ブランドを確立し、販路を広げる |
| 成熟期 | 売上の伸びが鈍化し、競争が激しい。差別化や、既存顧客の維持を図る |
| 衰退期 | 売上が減少する。撤退や、投資の縮小を検討する |

### 価格戦略と販売促進

| 用語 | 内容 |
|---|---|
| ペネトレーション価格 | 低価格で早期に市場シェアを獲得する |
| スキミング価格 | 高価格で早期に開発費を回収する |
| ダイナミックプライシング | 需要と供給の状況に応じて価格を変動させる |
| プッシュ戦略 | 販売員や流通業者への働きかけで、製品を消費者に押し出す |
| プル戦略 | 広告などで消費者の需要を喚起し、消費者に指名買いさせる |

顧客を最終購入日（Recency）、購入頻度（Frequency）、購入金額（Monetary）で分析する**RFM分析**、オンラインとオフラインの販路を統合する**オムニチャネル**もよく出題されます。

## ビジネス戦略と評価

### バランススコアカード（BSC）

財務だけでなく、4つの視点のバランスで戦略を評価・管理する手法です。

| 視点 | 例 |
|---|---|
| 財務 | 売上高、利益率 |
| 顧客 | 顧客満足度、リピート率 |
| 業務プロセス | 納期遵守率、不良率 |
| 学習と成長 | 従業員のスキル、資格の取得数 |

### 目標と指標

- **KGI**（重要目標達成指標）：最終的な目標の達成度を測る指標（例：年間売上高10億円）
- **CSF**（重要成功要因）：目標の達成に決定的な影響を与える要因
- **KPI**（重要業績評価指標）：CSFの達成度を測る中間的な指標（例：月間の新規顧客数）
- **OKR**：野心的な目標（Objectives）と、測定可能な主要な成果（Key Results）を組み合わせる目標管理の手法

### 経営管理システム

| システム | 内容 |
|---|---|
| ERP | 販売、生産、会計、人事などの基幹業務を統合し、経営資源を一元的に管理する |
| SCM | 調達から生産、物流、販売までの供給の流れ全体を最適化する |
| CRM | 顧客との関係を管理し、長期的な関係の維持と顧客満足の向上を図る |
| SFA | 営業活動を支援し、商談の進捗や顧客情報を共有する |
| ナレッジマネジメント | 個人のもつ知識やノウハウを、組織で共有して活用する |

## 技術戦略マネジメント

**MOT**（技術経営）は、技術を事業の成果に結びつけるための経営の考え方です。

| 用語 | 内容 |
|---|---|
| 技術ロードマップ | 技術の将来の進展を時間軸で示し、研究開発の計画に使う |
| 魔の川、死の谷、ダーウィンの海 | 研究 → 開発 → 事業化 → 産業化の各段階の間にある障壁。死の谷は開発から事業化への壁 |
| イノベーションのジレンマ | 優良な大企業が既存顧客の要求に応えるほど、破壊的イノベーションに対応できず、新興企業に市場を奪われる |
| プロダクトイノベーション | 新しい製品やサービスを生み出す |
| プロセスイノベーション | 製造方法や業務の手順を革新する |
| オープンイノベーション | 社外の技術やアイディアを積極的に取り込み、自社の技術と組み合わせる |
| キャズム | 新製品の普及で、新しいもの好きの初期採用者と、実利を重視する前期多数派の間にある大きな溝 |
| ハイプ・サイクル | 新技術への期待が、過度な期待のピーク → 幻滅期 → 啓発期 → 生産性の安定期と推移する様子を示す |
| デザイン思考 | 利用者への共感から課題を定義し、試作と検証を繰り返して解決策を探る |
| リーンスタートアップ | 最小限の製品（MVP）を素早く作って市場で検証し、学びを基に改善を繰り返す |
