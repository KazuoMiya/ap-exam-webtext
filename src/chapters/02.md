## データ構造

### 配列とリスト

- **配列**：同じ型の要素を連続した領域に並べる。添字で任意の要素に直接アクセスできる（O(1)）が、途中への挿入・削除は後ろの要素をずらす必要がある
- **線形リスト**：各要素が次の要素へのポインタを持つ。挿入・削除はポインタの付け替えだけで済むが、先頭からたどらないと目的の要素に到達できない
- 双方向リスト（前後のポインタを持つ）、環状リスト（末尾が先頭を指す）もある

### スタックとキュー

| 構造 | 取り出し順 | 操作 | 用途 |
|---|---|---|---|
| スタック | 後入れ先出し（LIFO） | push、pop | 関数呼出しの戻り先、逆ポーランド記法の計算、深さ優先探索 |
| キュー | 先入れ先出し（FIFO） | enqueue、dequeue | 印刷待ち、プロセスの実行待ち、幅優先探索 |

### 木構造

- **2分木**：各節が最大2つの子を持つ木
- **2分探索木**：左の子孫 ＜ 節 ＜ 右の子孫が常に成り立つ。中間順に走査すると昇順に並ぶ
- **完全2分木**：最下段以外がすべて埋まり、最下段は左から詰まっている木。配列で表現でき、添字1から始めると節 i の子は 2i と 2i＋1、親は i ÷ 2（切捨て）
- **ヒープ**：親が子以上（または以下）という条件を満たす完全2分木。最大値（最小値）は根にあるので O(1) で参照できる。根の取り出しと要素の追加は、ヒープの再構成を含めて O(log n)。優先度付きキューに使う
- **平衡木**（AVL木、B木）：左右の高さの偏りを抑え、探索を O(log n) に保つ。B木やB＋木はデータベースの索引に使われる

### 木の走査

| 走査順 | 訪問順 | 使いどころ |
|---|---|---|
| 先行順（前順） | 節 → 左 → 右 | 木の複製 |
| 中間順（間順） | 左 → 節 → 右 | 2分探索木を昇順に出力 |
| 後行順（後順） | 左 → 右 → 節 | 構文木から逆ポーランド記法を得る |

<div class="box point" markdown="1">

先行順と中間順の2つが分かれば、元の2分木を1つに決められます。先行順の先頭が根で、中間順の中でその根より左にあるのが左部分木、右にあるのが右部分木です。この分割を部分木ごとに繰り返します。

</div>

### ハッシュ表

キーからハッシュ関数で格納位置を計算するので、探索は平均 O(1) です。異なるキーが同じ位置になることを**衝突**（シノニムの発生）といい、次の方法で解決します。

- **オープンアドレス法**：空いている別の位置を探して格納する（例：1つ後ろを順に調べる線形探査）
- **チェイン法**：同じ位置のデータをリストでつなぐ

### グラフ

節点（ノード）と辺（エッジ）で構成されます。経路探索ではダイクストラ法（辺の重みが非負の最短経路）がよく出題されます。

## 探索と整列のアルゴリズム

### 計算量（オーダ記法）

データ数 n が増えたときに処理量がどの程度増えるかを O( ) で表します。主要な項だけを残し、係数は無視します。

| オーダ | 例 | n が10倍になると |
|---|---|---|
| O(1) | ハッシュ探索、配列の添字アクセス | 変わらない |
| O(log n) | 2分探索 | 少し増える |
| O(n) | 線形探索 | 10倍 |
| O(n log n) | クイックソート（平均）、マージソート、ヒープソート | 約10倍強 |
| O(n<sup>2</sup>) | バブルソート、選択ソート、挿入ソート | 100倍 |

### 探索

- **線形探索**：先頭から順に比較。平均比較回数は約 n/2、最大 n
- **2分探索**：**整列済み**のデータの中央と比較し、探索範囲を半分ずつに絞る。最大比較回数は約 log<sub>2</sub>n＋1。1,000件でも最大10回程度
- **ハッシュ探索**：衝突がなければ1回

### 整列

| 方法 | 考え方 | 平均 | 最悪 | 安定 |
|---|---|---|---|---|
| バブルソート | 隣どうしを比較して交換 | O(n<sup>2</sup>) | O(n<sup>2</sup>) | 安定 |
| 選択ソート | 未整列部分の最小値を選んで先頭と交換 | O(n<sup>2</sup>) | O(n<sup>2</sup>) | 不安定 |
| 挿入ソート | 整列済み部分の適切な位置に挿入 | O(n<sup>2</sup>) | O(n<sup>2</sup>) | 安定 |
| クイックソート | 基準値（ピボット）で大小に分割して再帰 | O(n log n) | O(n<sup>2</sup>) | 不安定 |
| マージソート | 半分に分けて整列し、併合 | O(n log n) | O(n log n) | 安定 |
| ヒープソート | ヒープを作り最大値を順に取り出す | O(n log n) | O(n log n) | 不安定 |

**安定**とは、同じキーの要素の相対的な順序が整列後も保たれることです。挿入ソートはほぼ整列済みのデータに対して高速（O(n)に近い）です。クイックソートは、整列済みのデータで先頭をピボットにすると分割が偏り、最悪の O(n<sup>2</sup>) になります。

<div class="box caution" markdown="1">

バブルソートの交換回数は、データ中の**逆順の組（転倒数）**の個数と一致します。[5, 3, 4, 1, 2] なら (5,3)(5,4)(5,1)(5,2)(3,1)(3,2)(4,1)(4,2) の8組なので、交換は8回です。

</div>

## 再帰

関数が自分自身を呼び出す構造を**再帰**といいます。必ず**終了条件**を持たせ、呼出しのたびに問題を小さくします。呼出しの情報はスタックに積まれます。

```
○整数型: fib(整数型: n)
  if (n ≦ 1)
    return n
  endif
  return fib(n − 1) ＋ fib(n − 2)
```

この素朴なフィボナッチ関数は、同じ値を何度も計算するため呼出し回数が指数的に増えます。fib(5) の呼出しは合計15回です。計算済みの結果を保存して再利用する工夫を**メモ化**（動的計画法）といいます。

## 擬似言語の読み方

科目Bの問3（プログラミング）では、IPAの擬似言語でアルゴリズムが示されます。基本の記法を押さえておきましょう。

| 記法 | 意味 |
|---|---|
| `○整数型: f(整数型: x)` | 手続・関数の宣言。戻り値の型と引数 |
| `整数型: a, b` | 変数の宣言 |
| `a ← b ＋ 1` | 代入 |
| `if (条件) … elseif … else … endif` | 選択処理 |
| `while (条件) … endwhile` | 前判定の繰返し |
| `do … while (条件)` | 後判定の繰返し（最低1回実行） |
| `for (i を 1 から n まで 1 ずつ増やす) … endfor` | 回数の決まった繰返し |
| `配列[i]` | 配列の要素。特に断りがなければ添字は1から |
| `mod` | 剰余（余り） |

<div class="box point" markdown="1">

擬似言語は**トレース表**で追うのが確実です。変数を列に並べ、1行実行するごとに値を書き込みます。ループの1回目、2回目、最後の回を特に丁寧に追うと、境界の誤り（1回多い・少ない）を見抜けます。

</div>

```
○整数型: gcd(整数型: a, 整数型: b)
  整数型: r
  while (b が 0 と等しくない)
    r ← a mod b
    a ← b
    b ← r
  endwhile
  return a
```

これは**ユークリッドの互除法**で最大公約数を求める関数です。gcd(1071, 462) は、余りが 147 → 21 → 0 と変化し、21 を返します。

## プログラム言語と言語処理

### 言語処理系

- **コンパイラ**：原始プログラム全体を機械語の目的プログラムに翻訳してから実行する
- **インタプリタ**：原始プログラムを1命令ずつ解釈しながら実行する
- **リンカ**（連係編集プログラム）：複数の目的プログラムやライブラリを結合して実行可能なプログラムを作る
- **JITコンパイラ**：実行時に中間コードを機械語に変換する

コンパイラは **字句解析 → 構文解析 → 意味解析 → 最適化 → コード生成** の順に処理します。字句解析は文字の並びを字句（トークン）に分け、構文解析は文法に従って構文木を作ります。

### オブジェクト指向

| 用語 | 意味 |
|---|---|
| カプセル化 | データと操作をまとめ、内部の実装を外部から隠す（情報隠蔽） |
| クラスとインスタンス | クラスは設計図、インスタンスはクラスから作った実体 |
| 継承（汎化） | 上位クラスの属性や操作を下位クラスが引き継ぐ |
| 多態性（ポリモーフィズム） | 同じメッセージに対して、オブジェクトごとに異なる振る舞いをする |
| オーバーライド | 下位クラスで上位クラスの操作を再定義する |

### その他の言語

HTML（Webページの構造）、CSS（見た目）、XML（タグで任意の構造を表すマークアップ言語）、JSON（JavaScriptのオブジェクト表記に基づく軽量なデータ交換形式）は頻出です。
