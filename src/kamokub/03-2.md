---本文
二つの文字列に共通して現れる部分列のうち、最も長いものを**最長共通部分列**（以下、LCSという）という。部分列とは、元の文字列からいくつかの文字を取り除き、残った文字を順序を変えずに並べたものである。文字は連続していなくてもよい。たとえば、"ABCB" と "BCAB" のLCSの一つは "BCB" であり、その長さは3である。

LCSは、文書の差分の表示や、遺伝子の配列の比較などに利用されている。

### 〔LCSの長さの求め方〕

文字列 s の先頭から i 文字目までの部分と、文字列 t の先頭から j 文字目までの部分のLCSの長さを L[i, j] とする。L[i, j] は、次の規則で求められる。

- i が0、または j が0のとき、L[i, j] は0である。
- s の i 文字目と t の j 文字目が等しいとき、L[i, j] は L[i − 1, j − 1] に1を加えた値である。
- s の i 文字目と t の j 文字目が異なるとき、L[i, j] は L[i − 1, j] と L[i, j − 1] の大きい方の値である。

この規則に従い、i と j の小さい方から順に表を埋めていくと、同じ計算を繰り返さずに L[m, n]（m は s の長さ、n は t の長さ）を求められる。このように、小さな部分問題の解を表に記録し、それを使って大きな問題の解を求める方法を、動的計画法という。

### 〔プログラムで用いる記法〕

- s[i] は文字列 s の i 番目の文字を表す。先頭の文字は1番目である。length(s) は s の長さを返す。
- 二次元配列 L の要素は L[i, j] で表す。L の添字は、行、列とも0から始まる。
- max(a, b) は、a と b の大きい方の値を返す。

### 〔プログラム1〕

```
○整数型: lcsLength(文字列型: s, 文字列型: t)
  整数型: m ← length(s)
  整数型: n ← length(t)
  整数型の二次元配列: L ← (m ＋ 1)行 (n ＋ 1)列の配列。全要素の初期値は 0
  整数型: i, j
  for (i を 1 から m まで 1 ずつ増やす)
    for (j を 1 から n まで 1 ずつ増やす)
      if (s[i] が t[j] と等しい)
        L[i, j] ←   a
      else
        L[i, j] ← max(L[i − 1, j],   b  )
      endif
    endfor
  endfor
  return   c
```

### 〔表のトレース〕

s が "ABCB"、t が "BCAB" のとき、プログラム1の実行が終わった時点の L の内容は表1のとおりである。

表1　L の内容（行が i、列が j）

| | j＝0 | 1（B） | 2（C） | 3（A） | 4（B） |
|---|---|---|---|---|---|
| i＝0 | 0 | 0 | 0 | 0 | 0 |
| 1（A） | 0 | 0 | 0 | 1 | 1 |
| 2（B） | 0 | 1 | 1 | 1 | ア |
| 3（C） | 0 | 1 | イ | 2 | 2 |
| 4（B） | 0 | 1 | 2 | ウ | 3 |

### 〔LCSそのものを求める〕

LCSの長さだけでなく、LCSの文字列そのものを求めたい。そこで、プログラム1で作成した L を、右下の L[m, n] から左上に向かってたどるプログラム2を作成した。

```
○文字列型: lcsString(文字列型: s, 文字列型: t, 整数型の二次元配列: L)
  文字列型: result ← ""
  整数型: i ← length(s)
  整数型: j ← length(t)
  while ((i ＞ 0) and (j ＞ 0))
    if (s[i] が t[j] と等しい)
      result ← s[i] ＋ result
      i ← i − 1
      j ← j − 1
    elseif (L[i − 1, j] ≧ L[i, j − 1])
        d
    else
        e
    endif
  endwhile
  return result
```
---設問 1
プログラム1の空欄 a〜c に入れる適切な字句を答えよ。
---解答 1
- a：**L[i − 1, j − 1] ＋ 1**
- b：**L[i, j − 1]**
- c：**L[m, n]**

解説：本文の規則をそのままプログラムに置き換えます。科目Bのプログラミングでは、**本文の日本語の規則と、プログラムの行を一対一に対応づける**のが最も確実な解き方です。
---設問 2
表1の空欄 ア〜ウ に入れる数値を答えよ。
---解答 2
- ア：**2**
- イ：**2**
- ウ：**2**

解説：

- ア（i＝2、j＝4）：s[2] は B、t[4] は B で等しいので、L[1, 3] ＋ 1 ＝ 1 ＋ 1 ＝ 2
- イ（i＝3、j＝2）：s[3] は C、t[2] は C で等しいので、L[2, 1] ＋ 1 ＝ 1 ＋ 1 ＝ 2
- ウ（i＝4、j＝3）：s[4] は B、t[3] は A で異なるので、max(L[3, 3], L[4, 2]) ＝ max(2, 2) ＝ 2

等しいときは左斜め上、異なるときは上と左を見る、と覚えると速く埋められます。
---設問 3
プログラム1について、次の問いに答えよ。

（1）s の長さを m、t の長さを n とするとき、プログラム1の時間計算量をオーダ記法で答えよ。

（2）本文の規則を、表を使わずに再帰呼出しだけで素直に実装した場合、処理時間が非常に長くなることがある。その理由を35字以内で述べよ。

（3）プログラム1は、L の全体を保持している。LCSの長さだけを求めればよい場合、必要な領域を減らす方法を35字以内で述べよ。
---解答 3
（1）**O(mn)**

（2）解答例：**同じ引数の組に対する計算を、何度も繰り返し実行するから。**

（3）解答例：**直前の行と現在の行の、2行分の配列だけを保持する。**

採点のポイント：（2）は動的計画法の存在意義そのものです。再帰だけでは呼出しが指数的に増えます。（3）は、L[i, j] の計算に必要なのが i − 1 行目と i 行目だけであることに気付けるかが問われます。ただし、プログラム2のように後から表をたどる場合は、全体の保持が必要です。
---設問 4
プログラム2について、次の問いに答えよ。

（1）空欄 d、e に入れる適切な字句を答えよ。

（2）s が "ABCB"、t が "BCAB" のとき、表1の L を使ってプログラム2を実行した場合の戻り値を答えよ。
---解答 4
（1）d：**i ← i − 1**　e：**j ← j − 1**

（2）**BCB**

解説：値が大きい方、つまりLCSの長さを保ったまま進める方向へ移動します。上（L[i − 1, j]）が左以上なら上へ、そうでなければ左へ進みます。

トレース：(i, j) ＝ (4, 4) は B と B が等しいので B を採用して (3, 3) へ。(3, 3) は C と A が異なり、L[2, 3] ＝ 1、L[3, 2] ＝ 2 なので左の (3, 2) へ。(3, 2) は C と C が等しいので C を採用して (2, 1) へ。(2, 1) は B と B が等しいので B を採用して (1, 0) へ。j が0になって終了し、先頭に追加していった結果は "BCB" です。
