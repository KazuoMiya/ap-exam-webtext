LEAD: 配列で表した最小ヒープへの追加と取出しのプログラムを読み、空欄補充とトレースを行います。
---本文
受け付けた順ではなく、優先度の高い順にデータを取り出すデータ構造を、優先度付きキューという。ここでは、値が小さいほど優先度が高いものとし、**最小ヒープ**を使って優先度付きキューを実現する。

### 〔最小ヒープ〕

最小ヒープは、次の二つの条件を満たす2分木である。

- 条件1：最も深い段を除いて節がすべて埋まっており、最も深い段は左から順に詰まっている（完全2分木）。
- 条件2：どの節の値も、その子の値以下である。

条件2から、最小の値は常に根にある。

最小ヒープは、配列 heap で表す。根を heap[1] に格納し、heap[k] の左の子を heap[2k]、右の子を heap[2k ＋ 1] に格納する。したがって、heap[k]（k ≧ 2）の親は heap[k ÷ 2]（小数点以下は切捨て）である。格納されている要素の数は、大域変数 size で管理する。

### 〔要素の追加〕

要素を追加するときは、配列の末尾に要素を置き、親の値より小さい間、親と交換しながら根の方向へ移動させる。

```
○add(整数型: x)
  整数型: k
  size ← size ＋ 1
  heap[size] ← x
  k ← size
  while ((k ＞ 1) and (heap[  a  ] ＞ heap[k]))
    heap[  a  ] と heap[k] の値を交換する
    k ←   a
  endwhile
```

### 〔最小の要素の取出し〕

最小の要素を取り出すときは、根の値を戻り値として保存し、配列の末尾の要素を根に移してから、子の値より大きい間、小さい方の子と交換しながら葉の方向へ移動させる。

```
○整数型: poll()
  整数型: top ← heap[1]
  整数型: k ← 1
  整数型: c
  heap[1] ← heap[size]
  size ← size − 1
  while (  b   ≦ size)
    c ← 2 × k
    if ((c ＋ 1 ≦ size) and (heap[c ＋ 1] ＜ heap[c]))
      c ← c ＋ 1
    endif
    if (heap[k] ≦ heap[c])
      繰返しを抜ける
    endif
    heap[k] と heap[c] の値を交換する
    k ← c
  endwhile
  return top
```

### 〔利用例〕

空の最小ヒープに対して、add(7)、add(4)、add(9)、add(2)、add(6)、add(1) をこの順に実行した。その後、poll() を2回実行した。
---設問 1
プログラム中の空欄 a、b に入れる適切な字句を答えよ。
---解答 1
- a：**k ÷ 2**（小数点以下は切捨て）
- b：**2 × k**

解説：a は親の添字です。b は「左の子が存在する間」という継続条件で、左の子の添字 2 × k が size 以下であれば、少なくとも一つの子があります。
---設問 2
〔利用例〕の6回の add を実行した直後について、次の問いに答えよ。

（1）heap[1] から heap[6] の値を、順に答えよ。

（2）6回の add の実行全体で、値の交換が行われた回数の合計を答えよ。
---解答 2
（1）**1, 4, 2, 7, 6, 9**

（2）**5回**

トレース：

| 操作 | 交換 | heap の内容 |
|---|---|---|
| add(7) | 0回 | 7 |
| add(4) | 1回（7と交換） | 4, 7 |
| add(9) | 0回 | 4, 7, 9 |
| add(2) | 2回（7、4と交換） | 2, 4, 9, 7 |
| add(6) | 0回（親の4より大きい） | 2, 4, 9, 7, 6 |
| add(1) | 2回（9、2と交換） | 1, 4, 2, 7, 6, 9 |

add(1) では、末尾の heap[6] に置いた1の親は heap[3] の9です。添字から親を正しく求めることが要点です。
---設問 3
〔利用例〕で、6回の add の後に poll() を2回実行した。次の問いに答えよ。

（1）1回目と2回目の poll() の戻り値を、それぞれ答えよ。

（2）2回目の poll() を実行した直後の heap[1] から heap[4] の値を、順に答えよ。
---解答 3
（1）1回目：**1**　2回目：**2**

（2）**4, 6, 9, 7**

トレース：

- 1回目：根の1を保存。末尾の9を根に移し、size は5。子は4と2で、小さい方の2と交換する。移動先の heap[3] の左の子の添字は6で size を超えるので終了。heap は 2, 4, 9, 7, 6。
- 2回目：根の2を保存。末尾の6を根に移し、size は4。子は4と9で、小さい方の4と交換する。移動先の heap[2] の子は heap[4] の7だけで、6 ≦ 7 なので終了。heap は 4, 6, 9, 7。
---設問 4
次の問いに答えよ。

（1）要素数が n の最小ヒープに対する add と poll の時間計算量を、オーダ記法で答えよ。また、その理由を30字以内で述べよ。

（2）poll の中で、二つの子のうち「小さい方の子」と交換している。大きい方の子と交換してはならない理由を、最小ヒープの条件に着目して40字以内で述べよ。

（3）n 個の値をすべて add した後、poll を n 回繰り返すと、値を昇順に取り出せる。この整列法の名称を答えよ。
---解答 4
（1）**O(log n)**　理由の解答例：**交換の回数は、最大でも木の高さ分で済むから。**

（2）解答例：**大きい方の子が親になると、もう一方の子より大きくなり、条件2を満たさないから。**

（3）**ヒープソート**

採点のポイント：（1）は完全2分木の高さが約 log<sub>2</sub>n であることが根拠です。（2）は「親はどちらの子よりも小さくなければならない」という条件2を、交換後の状態に当てはめて説明します。（3）のヒープソートは全体で O(n log n) です。
