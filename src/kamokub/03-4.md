TITLE: 幅優先探索による迷路の最短手数の計算
FIELD: プログラミング
SLOT: 問3相当（選択）
LEVEL: 本番級
TIME: 25
LEAD: キューを使った幅優先探索の空欄補充、探索順のトレース、スタックに変えた場合の違いを問います。
---本文
マス目状の迷路で、スタートからゴールまでの最短の手数を求めるプログラムを作成する。

### 〔迷路の表現〕

迷路は、縦 R 行、横 C 列のマスで構成される。上から r 行目、左から c 列目のマスを (r, c) と表す。行と列の番号は1から始まる。各マスは、通路か壁のいずれかである。1手で、上下左右に隣り合う通路のマスへ移動できる。壁のマスと迷路の外へは移動できない。

迷路は、二次元配列 maze で表す。maze[r, c] の値が 0 のとき通路、1 のとき壁である。図1に、4行4列の迷路の例を示す。S はスタート、G はゴールで、どちらも通路である。

図1　迷路の例（■は壁）

| | 1列 | 2列 | 3列 | 4列 |
|---|---|---|---|---|
| 1行 | S | | ■ | |
| 2行 | | ■ | ■ | |
| 3行 | | | | ■ |
| 4行 | ■ | | | G |

### 〔探索の方法〕

スタートから近いマスの順に調べる幅優先探索を用いる。

- 二次元配列 dist に、スタートから各マスまでの最短の手数を記録する。初期値は、まだ訪れていないことを表す −1 とする。
- スタートのマスの dist を 0 にして、キューに追加する。
- キューが空になるまで、次の処理を繰り返す。キューの先頭からマスを一つ取り出す。そのマスがゴールであれば、そのマスの dist の値を返して終了する。ゴールでなければ、上、下、左、右の順に隣のマスを調べ、迷路の中にある通路で、まだ訪れていないマスであれば、dist に「取り出したマスの dist ＋ 1」を記録して、キューの末尾に追加する。
- ゴールに到達せずにキューが空になったら、到達できないことを表す −1 を返す。

### 〔プログラムで用いる記法〕

- キュー q に対する操作として、末尾に追加する enqueue(q, r, c)、先頭から取り出す dequeue(q)、空かどうかを調べる isEmpty(q) を用いる。dequeue(q) は、取り出したマスの行と列の組を返す。
- 配列 dr と dc は、上、下、左、右の順に、行と列の移動量を格納した配列で、添字は1から始まる。dr は {−1, 1, 0, 0}、dc は {0, 0, −1, 1} である。
- and は、左側の式が偽のとき、右側の式を評価しない。

### 〔プログラム〕

```
○整数型: shortest(整数型の二次元配列: maze, 整数型: R, 整数型: C,
                 整数型: sr, 整数型: sc, 整数型: gr, 整数型: gc)
  整数型の二次元配列: dist ← R行C列の配列。全要素の初期値は −1
  キュー: q ← 空のキュー
  整数型: r, c, nr, nc, k
  dist[sr, sc] ← 0
  enqueue(q, sr, sc)
  while (isEmpty(q) が偽)
    (r, c) ← dequeue(q)
    if ((r が gr と等しい) and (c が gc と等しい))
      return   a
    endif
    for (k を 1 から 4 まで 1 ずつ増やす)
      nr ← r ＋ dr[k]
      nc ← c ＋ dc[k]
      if ((nr ≧ 1) and (nr ≦ R) and (nc ≧ 1) and (nc ≦ C))
        if ((maze[nr, nc] が 0 と等しい) and (  b  ))
          dist[nr, nc] ←   c
          enqueue(q, nr, nc)
        endif
      endif
    endfor
  endwhile
  return −1
```
---設問 1
プログラム中の空欄 a〜c に入れる適切な字句を答えよ。
---解答 1
- a：**dist[r, c]**
- b：**dist[nr, nc] が −1 と等しい**
- c：**dist[r, c] ＋ 1**

解説：b は「まだ訪れていない」ことの判定です。これがないと、訪問済みのマスを何度もキューに追加してしまい、処理が終わらなくなります。本文の「探索の方法」の各文が、プログラムのどの行に対応するかを突き合わせて埋めます。
---設問 2
図1の迷路で、スタートを (1, 1)、ゴールを (4, 4) としてプログラムを実行した。次の問いに答えよ。

（1）dequeue で取り出されるマスを、取り出される順に、4番目まで答えよ。

（2）プログラムの戻り値を答えよ。

（3）プログラムが終了するまでに、enqueue が実行される回数を答えよ。
---解答 2
（1）**(1, 1)、(2, 1)、(1, 2)、(3, 1)**

（2）**6**

（3）**9回**

トレース：(1, 1) を取り出し、下の (2, 1) と右の (1, 2) を追加します（上と左は迷路の外）。(2, 1) を取り出し、下の (3, 1) を追加します。(1, 2) からは、新たに進めるマスがありません。(3, 1) から (3, 2)、(3, 2) から (4, 2) と (3, 3)、(4, 2) から (4, 3)、(3, 3) からは新たなマスがなく、(4, 3) から (4, 4) を追加します。(4, 4) を取り出した時点でゴールなので、dist の値 6 を返します。

最短の経路は (1,1)→(2,1)→(3,1)→(3,2)→(3,3) または (4,2)→(4,3)→(4,4) で6手です。enqueue は、スタートの1回と、訪れた残りの8マスの分で、合計9回です。右上の (1, 4) と (2, 4) は、壁に囲まれていて到達できません。
---設問 3
このプログラムについて、次の問いに答えよ。

（1）幅優先探索で、ゴールのマスを最初に取り出したときの dist の値が、最短の手数になる理由を、40字以内で述べよ。

（2）キューの代わりにスタックを用いて、最後に追加したマスから先に取り出すように変更した。この探索の名称を答えよ。また、変更後のプログラムの戻り値について、適切な説明を35字以内で述べよ。
---解答 3
（1）解答例：**スタートからの手数が小さいマスから順に、キューから取り出されるから。**

（2）名称：**深さ優先探索**

説明の解答例：**ゴールには到達するが、戻り値が最短の手数とは限らない。**

採点のポイント：キューは先に入れたものを先に取り出すので、手数0のマス、手数1のマス、手数2のマス、という順に処理されます。スタックにすると、一つの方向へ行けるところまで進むので、遠回りの経路で先にゴールへ着くことがあります。なお、このプログラムは「最初に訪れたとき」に dist を記録するので、スタックに変えると dist の値そのものが最短でなくなります。
---設問 4
マスの数を N（＝ R × C）とするとき、次の問いに答えよ。

（1）このプログラムの時間計算量を、オーダ記法で答えよ。また、その理由を35字以内で述べよ。

（2）最短の手数だけでなく、最短の経路そのものを求められるようにしたい。プログラムにどのような情報の記録を追加すればよいか。35字以内で述べよ。
---解答 4
（1）**O(N)**　理由の解答例：**各マスは高々1回だけキューに追加され、隣の4マスを調べるだけだから。**

（2）解答例：**各マスについて、そのマスへ移動する直前にいたマスを記録する。**

採点のポイント：（1）は、訪問済みの判定によって、同じマスが2回追加されないことが根拠です。（2）は、ゴールから「直前のマス」を逆にたどることで、経路を復元できます。動的計画法で表を逆にたどって解を復元するのと同じ考え方です。
